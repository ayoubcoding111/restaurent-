┌─────────────────────────────────────────────────────────────┐
│ 🌐 API ENDPOINTS                                            │
└─────────────────────────────────────────────────────────────┘

GET    /api/items                    → Get all items
POST   /api/admin/login              → Admin login
POST   /api/items                    → Add item (with image)
PATCH  /api/items/:id/availability   → Toggle availability
DELETE /api/items/:id                → Delete item

┌─────────────────────────────────────────────────────────────┐
│ 🗄️  DATABASE                                                │
└─────────────────────────────────────────────────────────────┘

Database: restaurant_db
Table: items

Fields:
  • id (INT, PK, Auto Increment)
  • name (VARCHAR 255)
  • price (DECIMAL 10,2)
  • category (ENUM: pizzas, tacos, drinks, familypack)
  • image_url (VARCHAR 500)
  • is_available (TINYINT 1)
  • created_at (TIMESTAMP)
  • updated_at (TIMESTAMP)

┌─────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                          │
└─────────────────────────────────────────────────────────────┘

Problem: Cannot connect to database
Fix: Check MySQL is running & .env credentials

Problem: Port 3000 already in use
Fix: Change PORT in .env or kill process on 3000

Problem: Images not uploading
Fix: Check uploads/ directory exists and is writable

Problem: Admin button not showing
Fix: Clear sessionStorage and login again
